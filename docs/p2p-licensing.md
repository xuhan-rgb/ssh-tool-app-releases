# P2P 试用与激活码

本文件描述未配置 `MEMBERSHIP_API_URL` 的兼容模式。账号后台版本见 [账号后台说明](membership-backend.md)，其试用从用户主动领取时开始，支持账号恢复和按到期时间签名授权。

本地版本规则：首次成功建立 P2P 通道开始连续 7 天试用，所有连接配置共用试用。失败或原 SSH 回退不开始计时。到期后限制新的 P2P 连接及通道复用；当前已经建立的 SSH 会话保留，普通 SSH 免费。

激活码是 Ed25519 签名的长期授权，绑定 App 安装标识。App 只包含公钥，每次连接重新验证授权，前台和后台共用同一入口。没有应用内支付、自动扣款或在线订单验证。手工发码前应由开发者确认付款；App 不能验证付款本身。

## 发放激活码

1. 用户点击连接右侧三点菜单 →“P2P 连接设置”→“查看试用状态 / 输入激活码”，复制安装标识并输入激活码；也可以在连接设置中选择自动 P2P，点击“输入激活码解锁”。
2. 开发者确认收款后，在持有私钥的电脑执行：

```bash
python3 scripts/p2p_license.py issue \
  --key ~/.local/share/ssh-tool-app/licensing/p2p-issuer.pem \
  --installation '用户复制的安装标识'
```

3. 将输出的完整激活码交给用户。用户粘贴后点击“验证并解锁”。修改内容、错误签名、其他安装标识或其他产品的授权均会被拒绝。

工具需要 Python 的 `cryptography` 包。当前开发环境已生成签发私钥，位于上述仓库外路径，权限为 600。请安全备份私钥；不要将私钥放入仓库、APK、手机或日志。更新 APK 应使用同一公钥，以保留已有授权。

## 新发行方初始化

当前工作区已经配置公钥，无需再次初始化。只有为新的发行方建立独立密钥时执行：

```bash
python3 scripts/p2p_license.py init \
  --key /安全目录/新的签发私钥.pem \
  --public-output lib/services/p2p_license_public_key.dart
```

随后重新构建 App。工具拒绝覆盖已有私钥。替换 App 公钥后，原有激活码将失效。

## 本地版本限制

本兼容模式不使用 App 账号，激活码授权绑定安装标识，不绑定 SSH 用户或电脑，也不是跨手机的账号会员。清除数据、卸载或更换手机后，试用和授权记录不能恢复，需要重新签发激活码；覆盖安装更新通常保留记录。

本地记录会保留已观察到的最大时间，避免简单回调系统时间恢复已经到期的试用，但无法替代服务端可信时间。清除应用数据仍可重置试用，修改客户端也可以绕过本地限制。正式收费运营应加入服务端试用登记、授权恢复和订单验证，P2P 数据传输仍保持直连。

## 验证

`p2p_license_service_test.dart` 验证 7 天边界、不重复启动、回调时钟、签名与安装标识以及 Python 发码格式。`p2p_service_test.dart` 验证到期时阻止 P2P 启动、普通 SSH 可用、成功启动试用和失败不计时。组件测试验证授权文案、错误激活码反馈和首页到期解锁入口。
