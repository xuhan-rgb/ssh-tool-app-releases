# SSH Tool App

用 Android 手机连接 Linux 电脑上的 Codex，查看回复、发送消息，也可以继续电脑上的对话。

此仓库用于发布 Android 安装包和使用说明。

## 下载与安装

前往 [最新版本](https://github.com/xuhan-rgb/ssh-tool-app-releases/releases/latest)，在 Assets 中下载 APK 并安装。更新时直接安装新版，不要先卸载旧版，以保留已有连接配置。

## 使用前准备

- 电脑已安装并登录 Codex，并保持开机。
- 电脑已开启 SSH，手机能够访问电脑的 SSH 地址。
- 准备好 SSH 地址、端口、用户名和密码。

## 快速上手

1. 安装并打开 App，选择 Codex，点击“新建连接”。
2. 填写连接名称、主机地址、端口、用户名和密码，创建连接。
3. 未连接时点击电脑卡片进行连接；成功后再次点击进入对话列表。
4. 首次按页面提示完成 Codex 环境准备。
5. 在“远程打开”中继续已有对话，或点击新建对话并选择工作目录。
6. 输入消息，点击发送箭头，在手机查看电脑返回的回复。

## 对话操作

- `esc`：在对话页的三个点菜单中，停止当前正在执行的任务。
- `/clear`：在同一菜单中清空当前页面并开始新的空白对话，需要确认。旧记录保留，电脑当前窗口仍保留原对话。

## 可选 P2P

普通 SSH 免费，无需会员。P2P 是可选付费功能，先登录账号，再主动领取 7 天试用或开通会员。

首次使用 P2P 会通过已有 SSH 连接保存辅助程序，并启动用于直连的临时进程；连接结束后进程退出，文件保留供后续复用。首次 SSH 地址仍需可访问，是否能够直连取决于双方网络。

## 使用范围

目前应用内的 Codex 环境准备适用于 Linux 电脑。电脑需保持开机和联网，手机也需能够访问其连接地址。
